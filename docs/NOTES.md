# 实测笔记（HKC G27H7Pro，2026-10）

本文件记录开发过程中的**硬件实测数据**与**各轮修复记录**，供遇到同类显示器的人参考。
面向使用者的说明见 [../README.txt](../README.txt)。

显示器信息：EDID 名 `HKC2723…`，能力字符串里 `model(FALCON)`，2024 年第 30 周；
`WmiMonitorConnectionParams.VideoOutputTechnology = 10`（DisplayPort）；
MCCS 能力字符串：

```
(prot(monitor)type(lcd)model(FALCON)cmds(01 02 03 07 0C 4E F3 E3)
 vcp(02 0B 0C 10 12 14 16 18 1A 60 62 8D C0 C9 CA B6 C8 C6 DF FF)
 mccs_ver(2.0))
```

`cmds` 里有 `02 03` = 可读可写；`60(11120F)` = 输入源支持 `0x0F`(DP1) / `0x11`(HDMI1) / `0x12`(HDMI2)。

## 各 VCP 的实测结果（HDR 关闭状态）

| VCP | 功能 | 实测结果 |
|---|---|---|
| `0x10` | 亮度 0-100 | 写 100/25/72/65 全部生效，100↔25 肉眼明显 ✔ |
| `0x12` | 对比度 0-100 | 写 100/20 来回 4 次，黑位/层次明显 ✔ |
| `0x14` | 色温预设 | 可写 `0x06`(7500K) / `0x08`(9300K) / `0x0B`(用户1)，色调变化可见 ✔；`0x05`(6500K) 被固件拒绝（等 20 秒也不生效）；`0x01-0x04/0x07/0x0A` 会让它变成"未设置"(`0x00`)；读回值会滞后/错位 |
| `0x16/18/1A` | 红/绿/蓝增益 | 读 50/50/50，写 52 生效并回读 ✔ |
| `0x60` | 输入源 | DP1(`0x0F`) / HDMI1(`0x11`) / HDMI2(`0x12`) ✔ **上报的 `max` 是垃圾值 3，不能用来夹取** |
| `0x62` | 音量 | 能读（70/100），本机无内置喇叭 |
| `0x8D` | 静音 | 能读（2） |
| `0xC0` | 累计点亮时长 | 能读：3676 小时 |
| `0xC9/0xB6/0xC8/0xDF/0x02` | 固件/面板/控制器/VCP 版本 | 只读 |
| `0xD6` | 电源模式 | 能读（1/4），未测写入 |

**不支持**：水平/垂直位置、自动调整、缩放、HDR 开关（走 `Win+Alt+B`）、响应时间/Overdrive、锐度 —— 都不在显示器上报的能力列表里，只能在 OSD 里调。

## 软件调光（Gamma）的真实限制

实测 Windows/驱动对 `SetDeviceGammaRamp` 有硬性约束：**每个通道的最亮点必须 ≥ 32768（50%）**，曲线单调不减、相邻差 < 32768。所以：

- 单纯调光：最暗只能到 **51%**（50% 会被系统拒绝）
- 色温 3500K：能压到最暗约 **91%**（蓝通道被压到 50% 就到底了）
- 色温越暖，能压得越浅 —— **暖色和深调光互相挤占**

程序的做法：触到下限时按同一比例抬高三个通道（色温比例保持不变），状态行如实写出"（系统下限：实际只能到 xx%）"。
验证记录：14 组（调光 50-100% × 色温 3000-6500K）组合在实现"保比例退让"后全部被系统接受；修正前 50% 与 3500K+60% 等组合被拒。
退出程序或点"恢复默认"会写回标准曲线，不会把屏幕留在异常状态。

## HDR 的坑（最容易踩）

这台显示器进入 HDR 模式后，画面通路交给 HDR 信号，面板锁在最大亮度、由系统做 tone mapping。此时：

- VCP `0x10/0x12/0x14` 的写入会被固件"收下并存进寄存器"（**回读一切正常**），但完全不作用到面板
- 软件 Gamma 调光同样不生效

实测：HDR 开着时把亮度从 70 写到 25，屏幕毫无变化；关掉 HDR 后同样的操作肉眼立即可见（100↔25 来回 4 次，使用者确认）。

状态读取：`HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\MonitorDataStore\<显示器子键>\HDREnabled`
（本机子键 `HKC27230000000000001_1E_07E8_22`；注意 `AdvancedColorEnabled` **不是** HDR 标志位）。切换用 `Win+Alt+B`。

## 自动选源回跳

切到没接设备的接口后，显示器可能过几秒自动跳回有信号的接口（实测 HDMI-2 约 7 秒回跳，HDMI-1 观察 26 秒未回跳）。
这是显示器的"自动选择输入源"，不是工具故障 —— 在 OSD 里关掉它，或给该接口接上设备。

## 其它注意事项

1. 显示器 OSD 里的 **DDC/CI 必须保持开启**，否则所有写入都会失败。
2. 切到没有信号的接口会黑屏显示 `No Signal`，DDC/CI 依然有效，可以切回来。
3. Windows 自带的亮度滑块对外接屏无效（`WmiMonitorBrightness` 枚举不到这台），只能走 DDC/CI。
4. 色温 6500K 想调回去要在 OSD 里选一次，DDC 写不进去。
5. 屏幕时间的"亮屏"是程序运行时长、"使用中"是最近 2 分钟内有键鼠输入（推断值，非精确）。

## 验证记录（2026-10-16）

- 输入源 DP1→HDMI-1→DP1→HDMI-2→DP1 全部成功并回读确认
- 托盘图标左键 → 面板打开（截图确认）；右键 → 菜单
- HDR 关闭：面板绿字「○ HDR 已关闭 / 都可用」；HDR 开启：黄字「● HDR 已开启 / 现在都不可用」且滑杆与色温按钮置灰（两种状态均截图确认）
- HDR 切换往返（关→开→关）逐步查注册表确认；亮度 100↔25、对比度 100↔20、色温 9300K↔用户1 均经使用者肉眼确认
- Gamma 14 组组合全部被系统接受；`--gamma-reset` 可恢复标准曲线
- 分辨率：`--modes` 列出 168 个模式；3840×2160@160 ↔ 2560×1440@160 双向切换并回读确认
- 快捷键：显示器切到 HDMI-1（本机画面不可见）后按 `Ctrl+Shift+1` 成功切回 DisplayPort-1
- 屏幕时间：采样 70 秒后落盘「亮屏 1 分钟 / 使用中 1 分钟」

## 修复记录

**第一轮**（面板可用性）

1. HDR 卡小字顶部被切 → 单行标签高度按中文字形重算（`pt × 2.9`），HDR 卡加高
2. 切输入源失败（自身 bug）→ VCP `0x60` 不再按显示器上报的 `max` 夹取；毫秒级轮询证明写 `0x11` 后 600ms 切到 HDMI-1 并稳定 12 秒以上
3. 场景/色温缺选中态 → 新增高亮 + 右上角「当前：xxx」；手动改动后自动变「未套用预设」
4. 打开慢/先白一下 → DDC 读取全部移到后台线程，面板秒开（先画本地状态，值随后填入）+ 约 0.1 秒淡入 + 启动预热
   另修：整宽卡片标题标签在 WinForms z 序里会盖住后添加的数值标签（`Controls.Add` 把新控件放在后层）→ `BringToFront()`

**第二轮**（用户反馈）

1. 顶部副标题被标题挡住 → 标题/副标题各自给足高度
2. 点托盘图标再点一次应关闭 → 实现开/关切换；因为点击会让面板先失焦自隐藏，用"350ms 内刚隐藏过"判断，避免刚关又被打开
3. 开机自启动的灰色勾选框看不清 → 换成亮绿色开关按钮（开 = 绿底「开机自启动 ✓」）
4. 新增全局快捷键 + 右上角「⚙ 设置」（RegisterHotKey 注册在隐藏窗口上，`WM_HOTKEY` 触发后异步切输入源 + 气泡提示）
5. 设置窗口原来飘在面板上方很远 → 改成浮在面板正中，且打开设置期间面板不自动隐藏
6. 场景选中态不刷新 → **根因是自绘滑杆在"程序设值"时也触发了 `Scroll`**（原生 `TrackBar` 只在用户拖动时触发），"应用场景"里程序去设调光/色温滑杆的值时，事件把刚设好的 `currentScene` 重置成 `-1`。修法：滑杆加 `fromUser` 标志
7. 应用场景后概览页的硬件亮度/对比度数值与滑杆位置不同步 → 在同一个回调里一起更新

**第三轮**（用户反馈）

1. 场景与"色温预设"的关系讲清楚：场景调的是**软件色温（Gamma）**，色温预设那 3 个按钮是**显示器硬件 DDC `0x14`**，两层不是一回事、按钮不会跟着场景跳。色温卡里新增会动的一行「软件色温（Gamma）3600K · 夜间 场景」
2. 页签切换改成瞬间：切页签不再每次跑一遍 DDC 读取（沿用上次读数，超过 2 秒才重读）；4 个页面/卡片容器全部双缓冲；`DisplayModes.List()` 加 3 秒缓存（原来每画一行分辨率都要枚举 200 多个模式）。实测点击页签后 200 毫秒截图，页面已完整渲染
3. 去掉"亮度/对比度/色温预设"三张卡片标题下面那行无用小字，卡片高度相应收紧

**界面**（参考 MonitorBar 调整）

- 面板 360×648 → **360×760**；字号放大：标题 13pt、卡片标题 9.5pt、数值 13pt、大分辨率 16pt
